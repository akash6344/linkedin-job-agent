# Private beta playbook (25–50 users)

## Offer

Give each beta user a **30-day Pro Search pass** (no charge) in exchange for:

1. Completing onboarding in week 1
2. Approving or rejecting at least 10 drafts
3. Filling a mid-beta and end-beta survey
4. Consent to anonymized outcome metrics (matches, drafts, sends, replies, interviews)

## Recruiting channels

1. Engineering college placement cells / WhatsApp alumni groups
2. Job-search Discord / Telegram / WhatsApp communities
3. LinkedIn posts about “15-minute job-search setup” (no “1000 auto-applies” claims)
4. Bootcamps and resume coaches (referral code = +7 bonus days)

## Onboarding checklist for each user

- [ ] Account created
- [ ] Consents recorded (matching, email send, product updates)
- [ ] Resume uploaded + profile corrected
- [ ] Search preferences set (roles, location India/remote, experience cap)
- [ ] Gmail connected via OAuth (or skipped with form-only mode)
- [ ] Preview: saw ≥5 matches and ≥1 draft
- [ ] Beta tracker row created in `docs/validation/beta-tracker.csv`

## Weekly ops

| Week | Focus | Metric gates |
|------|-------|--------------|
| 0 | Invite + onboarding help | ≥60% finish onboarding |
| 1 | Match quality feedback | ≥40% return in week 2 |
| 2 | Draft quality + send friction | Approve/send rate tracked |
| 3 | Reply / interview outcomes | Qualitative wins documented |
| 4 | Pricing willingness resurvey | Decide one-time pass vs wait |

## Outcome metrics (consented, anonymized)

- Matches shown / week
- Drafts generated
- Drafts approved vs rejected
- Emails sent
- Forms completed (self-reported)
- Replies / interviews (self-reported)
- NPS and “would pay” at day 30

## Messaging rules

- Promise: setup in 15 minutes, review high-match drafts, stay organized
- Do **not** promise interviews, jobs, or unlimited auto-apply
- Do **not** claim LinkedIn ToS bypass or scrapers as a feature
